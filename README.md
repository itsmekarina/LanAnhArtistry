# LanAnhArtistry

LanAnhArtistry is a Vietnamese web workspace for literary translators. The public home page introduces the workspace; visitors can open the translation workspace from the “Vào workspace” links.

## Pages

- `/LanAnhArtistry/` — public landing page
- `/LanAnhArtistry/#/workspace` — translation workspace

## Run locally

Requires Node.js 20 or newer.

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and add your own Gemini API key to enable AI-assisted features.
3. Run `npm run dev`.

The GitHub Pages workflow builds the static site when changes are pushed to `main`.
